I2C Master-Slave Design Using Verilog
Overview:
This project implements the Inter-Integrated Circuit (I²C) Communication Protocol using Verilog HDL. It includes the design and verification of both I²C Master and I²C Slave modules, demonstrating serial communication between devices through the SDA (Serial Data) and SCL (Serial Clock) lines.
The project aims to provide a clear understanding of I²C protocol operations such as start condition generation, address transmission, data transfer, acknowledgment handling, and stop condition generation.

Features:
Verilog implementation of I²C Master and Slave
Start and Stop condition generation
7-bit slave addressing
Read and Write operations
Acknowledgment (ACK) handling
Serial data transfer using SDA line
Clock generation using SCL line
Functional verification through testbench simulation

I²C Protocol Basics:
I²C (Inter-Integrated Circuit) is a synchronous serial communication protocol that uses only two wires:
SCL (Serial Clock Line) – Generated by the Master.
SDA (Serial Data Line) – Used for data transfer between Master and Slave.

Communication Sequence:
Start Condition
Slave Address Transmission
Read/Write Bit
ACK from Slave
Data Transfer
ACK/NACK
Stop Condition

Master Module:
Responsibilities:
Generates SCL clock.
Initiates communication.
Sends slave address.
Performs data read/write operations.
Generates START and STOP conditions.
Handles ACK reception.

Inputs:
Clock (clk)
Reset (rst)
Data input
Slave address

Outputs:
SDA
SCL
Transfer status signals

Slave Module:
Responsibilities:
Detects START condition.
Receives address from Master.
Sends ACK signal.
Receives or transmits data.
Responds only to matching addresses.

Inputs:
SDA
SCL
Slave address

Outputs:
Data output
ACK response

Functional Operation:
Write Operation:
Master generates START condition.
Master sends Slave Address + Write Bit.
Slave acknowledges the address.
Master transmits data byte.
Slave sends ACK.
Master generates STOP condition.

Read Operation:
Master generates START condition.
Master sends Slave Address + Read Bit.
Slave acknowledges.
Slave transmits data byte.
Master sends ACK/NACK.
Master generates STOP condition.
